# ⚡ Picomatch Rust Browser TUI (`picomatch-tui-web`)

Interactive browser terminal UI for [`picomatch-rust`](../README.md) built with WebAssembly (WASM), HTML5/CSS3, and Xterm.js.

## 🚀 Free Hosting on Vercel

This directory (`picomatch-tui-web`) is a **100% static web application** with zero backend server requirements. It can be hosted on Vercel's Free Hobby Tier forever!

### Option 1: Deploy with Vercel CLI

```bash
npx vercel ./picomatch-tui-web --prod
```

### Option 2: Deploy via GitHub / Vercel Dashboard

1. Push your branch to GitHub.
2. Import the repository into your Vercel Dashboard.
3. Set **Root Directory** to `picomatch-tui-web`.
4. Click **Deploy**!

### Option 3: Local Testing

```bash
# Serve locally with Python:
cd picomatch-tui-web
python3 -m http.server 8080

# Open http://localhost:8080 in your browser
```
