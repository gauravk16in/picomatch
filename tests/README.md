# tests/ — Port Test Strategy

This directory hosts the PORT's test assets (the upstream suite stays untouched in `test/`). Strategy authority: `docs/differential-testing.md` + `docs/fuzzing.md`; mapping: `knowledge/test-inventory.md`.

| Path | Purpose | Created when |
|---|---|---|
| `corpus/` | JSONL oracle corpus (`v1/`) + SHA-256 manifest; the executable spec | Phase 1 |
| `differential/` | replay drivers + CLI protocol conformance tests (Rust side) | Phase 4+ |
| `fixtures/` | promoted mismatch/regression cases with classification metadata | Phase 4+ (as found) |
| `fuzz/` | fuzz seed corpus + target definitions reference (actual cargo-fuzz targets live in `fuzz/` workspace member per Rust Fuzz Book layout, Phase 9) | Phase 9 |

Rules:

1. No fabricated passing tests: suites here run against real artifacts only (CLI or library).
2. Every corpus case is generated by the oracle runner from the pinned commit (`4f41a8e`) — never hand-invented expectations without an oracle citation.
3. Mismatch cases are promoted with triage classification (PORT-BUG / SPEC-GAP / ORACLE-QUIRK / UPSTREAM-BUG) per docs/differential-testing.md §7.
4. The original mocha suite is executed through `test/adapter/` (Phase 8) — those driver files are tooling, not modifications of upstream tests.
